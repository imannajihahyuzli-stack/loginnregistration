# Login & Registration

## Setup
1. Create a project in the Firebase Console.
2. Add an Android app using the package name from app/build.gradle.
3. Download google-services.json and place it in the app/ folder.
4. Enable the Firebase services used (Authentication, Firestore, etc.).
5. Build and run.
